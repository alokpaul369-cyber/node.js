# 🟢 Node.js Practice

My hands-on practice while learning **Node.js** and **Express.js**, from raw `http` servers to Express routing.

![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white) ![Express](https://img.shields.io/badge/Express-000000?style=flat-square&logo=express&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=white)

## 📂 Contents

| Folder | What I practised |
|:--|:--|
| `Create a page/` | Serving HTML pages with the `http` module |
| `Parsing Request/` | Routing, reading form data and parsing request bodies |
| `Create a Calculator/` | A small calculator server split into modules |
| `Express.js/` | First steps with Express: routes and handlers |

## 🚀 Run an example

```bash
git clone https://github.com/alokpaul369-cyber/node.js.git
cd "node.js/Express.js"
npm install
npm start
```

Plain Node examples can be run directly, e.g. `node "Create a page/page.js"`.
